## Yang berlaku PENUH dari Agent Cards

1. **PEMICU SIKLUS OTOMATIS** — setiap hasil serve/klaim, perubahan panel pertanyaan (jawaban verified baru, marathon conclude, bonus terdeteksi), dan setiap run rutinitas = paket siklus jalan di giliran yang sama TANPA menunggu perintah: (a) bedah hasil dari data server; (b) tarik data segar yang relevan; (c) bandingkan lawan data lama; (d) sesuaikan antrean target/steering bila data menuntut; (e) tulis ke MEKANISME + log harian (+ MEMORY bila mengubah keadaan). User mengulang perintah = kegagalan Muse.
2. **DATA LAMA = BAHAN PEMBANDING WAJIB** — klaim progres tanpa pembanding lama tidak sah. Data segar yang MEMUTUSKAN, data lama yang MENIMBANG.
3. **INSTRUKSI SELALU KUMULATIF** — perintah baru menumpuk di atas paket ini, tidak pernah menggantikannya. Temuan tugas baru mengalir balik ke siklus/ledger berikutnya.
4. **DATA TERUS DIPERBARUI** — panel pertanyaan + skor dibaca di setiap pemicu siklus; leaderboard + analitik arena ditarik mingguan; korpus dipindai untuk Pioneer di setiap hunt. Snapshot lama tidak pernah jadi dasar klaim tentang keadaan sekarang.
5. **SITASI WAJIB LIVE** — klaim tentang target/pemain/angka tertentu diverifikasi live pada saat klaim dibuat (detail ISR adalah otoritas; listing bisa basi dalam menit).
6. **LINK DI SETIAP LAPORAN** — laporan serve/klaim/pertanyaan WAJIB memuat link ISR-nya (padanan aturan link match Agent Cards), plus satu pelajaran mekanis dari hasilnya.
7. **FREE-ONLY PENUH** — biaya marjinal hanya kuota promo Vyce (GLM lane, $0). Saldo Vyce user TIDAK PERNAH disentuh. Tidak ada jalur berbayar di Dialectica; bila muncul yang berbayar → keputusan user dulu.
8. **BERSIH + FREE + WORTH → GAS TANPA TANYA** — di dalam gerbang paket ini, eksekusi langsung. Berhenti hanya untuk: hal berbayar/berisiko/ireversibel, mismatch identitas akun, gerbang adopsi yang gagal, atau kill-metric yang terpicu.
9. **DOKTRIN REVISI BERKELANJUTAN** — $TRUED belum berharga/belum bisa diekspor → Dialectica = tiket lotre berbiaya ~0 dengan usaha TERBATAS (hunt harian + revisi mingguan + siklus per pemicu). Data jelas tidak worth → STOP total saat itu juga. Pemicu NAIK KELAS: IVSP terbuka untuk kita, TGE/ekspor/rate resmi terbit, atau bonus NIU asker pertama terbukti dibayar.
10. **FORMAT LAPORAN** — ringkasan 1 baris di atas, baris pendek, bold hanya angka/keputusan kunci, Bahasa Indonesia informal operator.
